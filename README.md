# Навигатор «МЕБЕЛЬ-2026»

Независимый статический портал для посетителей выставки: каталог участников, проверенные сайты и контакты, деловая программа, профили выступающих, публикации из связанных публичных Telegram-каналов, цифровые решения и практический гид.

**Сайт:** https://wwwparser.github.io/mebel-expo-2026/  
**Срез каталога:** официальный список на 13 ноября 2026 года; проверка каталога — 16 ноября. Ленты участников и спикеров обновлены 24 ноября 2026 года. Срез ассортимента и сайтов — 22 ноября.

## Что собрано

- 478 строк участников из официального каталога: название, страна и стенд.
- 284 сайта из официального путеводителя, привязанные к участникам по уникальному совпадению стенда; 201 сайт открылся при проверке. У 164 карточек добавлено краткое описание из метатега сайта.
- Публичные контакты сохранены только со связанных сайтов. Отсутствие сведений в карточке не означает, что контактов у компании нет.
- 26 записей деловой программы и 42 профиля выступающих из официальной страницы программы. Это анонсы, а не подтверждение состоявшегося выступления.
- 92 ссылки на Telegram, размещённые на сайтах участников; публичный просмотр показал сообщения у 61 канала. Собрано до 10 последних сообщений на канал, всего 523. У 456 публикаций есть фото или превью видео. Для остальных 31 Telegram не показал публичную ленту на дату проверки.
- Два подтверждённых решения для мебельных компаний: система БАЗИС и сервис Фабрикод. Ещё пять кандидатов оставлены на отдельную проверку, без приписывания им неустановленных услуг.
- Официальная схема павильона, выгрузки каталога CSV/JSON, экспорт цифровых решений и статья-памятка перед посещением.

Каждая карточка и редакционная публикация содержит первоисточники. Портал не аффилирован с АО «ЭКСПОЦЕНТР»; перед визитом проверьте время, доступ и программу на официальном сайте.

## Разработка

Генератор формирует автономный статический сайт в `docs/`.

```powershell
python -m pip install -r requirements.txt
python scripts/build_portal.py
python scripts/check_portal.py
python scripts/smoke_test.py
```

Для локального просмотра:

```powershell
python -m http.server 8000 --directory docs
```

Данные для публикации находятся в `data/portal/`. Сырые загрузки, логи обхода и секреты исключены через `.gitignore`. Обновления источников выполняйте отдельно; сборка сайта работает локально и не отправляет запросы к сайтам компаний.

## Обновление ленты фабрик

Срез 22 ноября 2026 года. В мебельных рубриках 2ГИС рассмотрено 266 859 строк с повторами по категориям, проверено 8 059 возможных Telegram-адресов. В рубрике мебельных фабрик Яндекс Карт по России и Беларуси для обхода выделено 5 647 адресов сайтов. Содержимое удалось получить по 1 983 адресам. Список дополнен каналами из официального путеводителя выставки. Для публикации требуются совпадение бренда или сайта и сообщения о готовой мебели. Широкопрофильные продавцы тоже встречаются. Каналы с редкими обновлениями сохраняют даты оригинальных сообщений.

В `data/portal/factory_channels.json` хранится реестр проверенных брендов. До трёх последних сообщений берутся для массовой выборки, до десяти — для расширенной. Анонсы можно добавить в `factory_attendance.json` после проверки цитаты, места, года и роли участника по конкретному посту. Чтобы обновить существующий реестр на текущую дату:

```powershell
python scripts/factory_feed.py collect
python scripts/factory_feed.py assemble
python scripts/build_portal.py
python scripts/check_portal.py
```

Сборщик сохраняет ответы по каждому каналу и позволяет повторить загрузку после сетевой ошибки. Если канал стал закрытым, перед новой публикацией нужно проверить запись реестра.
